Tutorial rápido (imagens e links)

No campo "Mensagem do Mural", você pode usar texto normal, links e imagens.

Link com texto personalizado

[Abrir Google](https://www.google.com)

Link automático

https://www.organife.com.br

Imagem no texto

![Banner](https://i.postimg.cc/xxxxx/imagem.png)

Imagem em linha única

img: https://i.postimg.cc/xxxxx/imagem.png

Como gerar URL da imagem no Postimages

  1. Acesse postimages.org.
  2. Clique em upload, cole a imagem ou arraste o arquivo.
  3. Após enviar, copie o link direto da imagem (de preferência PNG/JPG).
  4. Cole esse link no formato ![Texto](URL) ou img: URL.
